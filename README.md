# StructureLab — Windows

Версия приложения StructureLab для Windows, перенесённая из APK (0.1.0 TEST).
Веб-часть (`www/`) взята из APK без изменений. Обёртка — Electron.

## Сборка через GitHub
1. Создайте репозиторий на GitHub и загрузите в него все файлы этого архива.
2. Откройте вкладку **Actions** → **Build Windows EXE** → **Run workflow**.
   (Сборка также запускается при каждом пуше в `main`.)
3. Когда сборка завершится, файл `StructureLab-*.exe` появится в разделе **Artifacts** внизу страницы запуска.
4. Для релиза создайте тег, например `v0.1.0`: `git tag v0.1.0 && git push --tags`. EXE будет добавлен в **Releases**.

## Локальный запуск (если есть Node.js)
    npm install
    npm start

## Что изменено относительно APK
- Сохранение файлов: вместо нативного моста Android открывается системный диалог «Сохранить как».
- Кнопка «Назад» заменена клавишей Esc.
- Всё остальное (интерфейс, конвертация, 3D-просмотр, демо-модели) — без изменений.
